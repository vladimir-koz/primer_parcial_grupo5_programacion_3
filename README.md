# primer_parcial_grupo5_programacion_3
Este proyecto consiste en el desarrollo de una interfaz web basada en tarjetas interactivas, donde cada elemento permite registrar una acción de “me gusta” y modificar su comportamiento dinámicamente mediante JavaScript.

---

## Tecnologías y conceptos utilizados

- HTML semántico
- CSS (archivos externos)
- Flexbox para disposición de elementos
- JavaScript
- Manipulación del DOM
- Eventos (click)
- Cambios dinámicos de estilos y clases

---

## Funcionalidades

- Visualización de múltiples tarjetas
- Cada tarjeta contiene:
  - Título
  - Descripción
  - Botón de “me gusta”
- Contador individual de likes por tarjeta
- Actualización dinámica del contador
- Botón global para ordenar las tarjetas de mayor a menor cantidad de likes
